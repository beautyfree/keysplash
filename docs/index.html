Made by a parent

It started with one very curious toddler.

Our little one loved coming over to the computer and pressing every key. The original Cleaning Mode solved the practical problem by blocking input, but the blank screen made the computer feel off-limits.

We wanted that moment to feel more welcoming. KeySplash keeps the keyboard lock and turns the display into a canvas for colorful handprints, so a child can pretend to work while accidental keystrokes stay out of what was open.

One macOS permission

A clear setup for Accessibility access.

macOS requires this permission for apps that capture keyboard input. KeySplash explains the steps and does not lock the keyboard before access is available.

  1. In KeySplash, click Open Accessibility Settings.
  2. Find KeySplash in System Settings → Privacy & Security → Accessibility and switch it on. If it is missing, use the add button to choose KeySplash from Applications.
  3. Return to KeySplash. It checks access and starts when macOS applies the permission.

Good to know

A few quick answers.

Does KeySplash work on Windows or Linux?

No. KeySplash is a native Mac app and requires macOS 14 or later.

Does it block mouse clicks too?

Clicks outside the on-screen controls are intercepted, so you cannot accidentally interact with other apps during play. Use the Unlock button to end a session with the mouse.

Is KeySplash free?

Yes. Download it from the public GitHub Releases page at no cost. No account or subscription is required.

Does it support different keyboard layouts?

Yes. KeySplash maps physical key positions for ANSI, ISO, and JIS keyboard layouts.
