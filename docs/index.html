Made by a parent

A familiar moment inspired a better keyboard-cleaning mode.

KeySplash started with a toddler wandering over to the computer and pressing every key in sight. A simple cleaning mode could block typing, but a blank screen made the moment feel like “don’t touch.”

We wanted something gentler: let a child feel like they are using the computer, while helping keep accidental keystrokes out of whatever was open. So we turned the screen into a canvas for colorful handprints, mapped to where each key sits on the keyboard.

One macOS permission

Why KeySplash asks for Accessibility access

macOS requires this permission for apps that capture keyboard input. KeySplash needs it to pause typing during play mode.

  1. In KeySplash, choose Open Accessibility Settings.
  2. Find KeySplash in System Settings → Privacy & Security → Accessibility and switch it on. If it is missing, use the add button to choose KeySplash from Applications.
  3. Return to KeySplash. It checks access and starts when macOS has applied the permission.
You stay in control. The keyboard is not locked until access is available. During play, use the on-screen Unlock button or press Escape five times. macOS Force Quit remains available as an emergency exit.

Good to know

KeySplash questions

Does KeySplash work on Windows or Linux?

No. KeySplash is a native macOS app and requires macOS 14 or later.

Does it block mouse clicks too?

Clicks outside the on-screen controls are intercepted, so you cannot accidentally interact with other apps during play. Use the Unlock button to end a session with the mouse.

Is KeySplash free?

Yes. You can download KeySplash from the public GitHub Releases page at no cost. It does not require an account or subscription.

Does it support different keyboard layouts?

Yes. KeySplash maps key positions for ANSI, ISO, and JIS physical keyboard layouts.
