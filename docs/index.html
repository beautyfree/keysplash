The rest of your Mac stays put

Little taps leave handprints

Each key press places a colorful hand where that part of the keyboard maps on the screen. Quick flurries make the prints grow.

FAQ

Does KeySplash work on Windows or Linux?

No. KeySplash is a native Mac app and requires macOS 14 or later.

Does it block mouse clicks too?

Clicks outside the on-screen controls are intercepted, so you cannot accidentally interact with other apps during play. Use the Unlock button to end a session with the mouse.

Is KeySplash free?

Yes. Download it from the public GitHub Releases page at no cost. No account or subscription is required.

Does it support different keyboard layouts?

Yes. KeySplash maps physical key positions for ANSI, ISO, and JIS keyboard layouts.

Why does KeySplash need Accessibility access?

macOS requires this permission for apps that capture keyboard input. KeySplash explains the setup steps and does not lock the keyboard before access is available.

How do I allow Accessibility access?

In KeySplash, choose Open Accessibility Settings. Find KeySplash under System Settings → Privacy & Security → Accessibility and switch it on. If it is missing, use the add button to choose KeySplash from Applications.

How do I unlock the keyboard?

Click Unlock in the on-screen controls or press Escape five times.
